# 38 Glossary

- **Space**: the main tenant or scoped organization boundary in the platform.
- **DataModel**: structured configurable data-definition system.
- **EAV**: entity-attribute-value modeling system for highly dynamic schemas.
- **ChatbotVersion**: versioned chatbot configuration snapshot used for draft/publish style workflows.
- **Plugin Hub**: separate app for plugin ecosystem concerns.
- **Agent Loop**: orchestration/configuration layer for multi-agent chatbot behavior.
- **DashboardSpace / ReportSpace**: join models that scope analytics assets to spaces.
- **Knowledge Collection**: container for collaborative knowledge content.
- **Branding Config**: app-wide styling and visual configuration overlay.
- **System Settings**: runtime-configurable platform settings stored outside hardcoded code.
